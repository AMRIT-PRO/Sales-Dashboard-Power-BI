# 📊 Madhav Ecommerce Sales Dashboard

## 📌 Project Overview
This Power BI dashboard provides insights into Madhav Ecommerce sales performance. It helps analyze revenue, profit, quantity sold, customer behavior, payment methods, and product categories through interactive visualizations.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📈 Dashboard Metrics
- Total Sales Amount: 438K
- Total Profit: 37K
- Total Quantity Sold: 6K
- Average Order Value: 121K

## 🔍 Key Insights

### Customer Analysis
- Harivansh generated the highest sales amount.
- Madhav and Madan Mohan are among the top customers.

### State-wise Performance
- Maharashtra contributed the highest sales.
- Madhya Pradesh ranked second.
- Uttar Pradesh and Delhi followed behind.

### Category Analysis
- Clothing accounted for 63% of total quantity sold.
- Electronics contributed 21%.
- Furniture contributed 17%.

### Payment Mode Analysis
- Cash on Delivery (COD) was the most preferred payment method (44%).
- UPI contributed 21%.
- Debit Card and Credit Card accounted for the remaining transactions.

### Profit Analysis
- December generated the highest profit.
- Profit declined during May, July, and October.
- Printers and Bookcases were the most profitable sub-categories.

## 🎯 Features
- Interactive Dashboard
- KPI Cards
- Category-wise Analysis
- State-wise Sales Analysis
- Customer Insights
- Monthly Profit Trends
- Payment Method Analysis
